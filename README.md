# SimpleNotes

**SimpleNotes** è un editor di testo semplice, leggero ed intuitivo sviluppato con il linguaggio **Python** e le librerie **Tkinter**, **Datetime** e **Webbrowser**. Il software è stato progettato per offrire un'esperienza simile alla versione classica del Blocco Note di Windows, ma con funzionalità estese come la personalizzazione del tema.

---

## Funzionalità principali

SimpleNotes offre un set completo di strumenti organizzati in un'interfaccia pulita composta da quattro menu:

### File
* **Nuovo / Nuova finestra:** Gestisci più documenti contemporaneamente.
* **Apri / Salva / Salva con nome:** Gestione completa dei tuoi file di testo.
* **Esci:** Chiusura sicura dell'applicazione con richiesta del salvataggio se necessario.

### Modifica
* **Editing classico:** Annulla, Ripeti, Taglia, Copia, Incolla ed Elimina.
* **Strumenti avanzati:**
    * **Trova e Sostituisci:** Cerca parole specifiche e sostituiscile rapidamente.
    * **Ora/Data:** Inserimento rapido del timestamp corrente.
    * **Seleziona tutto:** Per gestire rapidamente l'intero documento.

### Visualizza
* **Personalizzazione tema:** Scegli tra **Tema chiaro** e **Tema scuro** per il massimo comfort visivo.
* **Aspetto:** Modifica il **Carattere** (font), mostra/nascondi la **Barra di stato** e attiva/disattiva la modalità **A capo automatico**.

### Supporto (?)
* **Guida:** Accesso diretto alla documentazione online.
* **Informazioni:** Dettagli sulla versione, il copyright e l'autore di SimpleNotes.
