Introduzione a Texty

Benvenuto nella Guida utente di Texty! Texty è un editor di testo semplice, leggero ed intuitivo progettato per semplificare la scrittura e la gestione degli appunti.

Con Texty puoi creare file di testo in modo rapido e intuitivo e non solo: puoi anche selezionare un'estensione diversa con cui salvare il tuo file, a scelta tra *.md, *.html, *.css, *.js e *.py.

Funzionalità

Ecco alcune funzionalità principali:
  • Nuovo file: Usa il menu File o le scorciatoie da tastiera per avere una pagina vuota.

  • Nuova finestra: Usa il menu File o le scorciatoie da tastiera per avere un'altra finestra se hai bisogno di lavorare su più file contemporaneamente.

  • Apri file: Usa il menu File o le scorciatoie da tastiera per aprire un file di testo esistente.

  • Salva file: Usa il menu File o le scorciatoie da tastiera per salvare il tuo lavoro nel formato che desideri.

  • Annulla, Ripeti: Usa i comandi nel menu Modifica o le scorciatoie da tastiera.

  • Taglia, Copia, Incolla, Elimina, Seleziona tutto: Usa i comandi nel menu Modifica o le scorciatoie da tastiera.

  • Ora/Data: Usa l'opzione nel menu Modifica o la relativa scorciatoia da tastiera per visualizzare il timestamp corrente.

  • Trova, Sostituisci: Usa il menu Modifica o le scorciatoie da tastiera per cercare o sostituire testo all'interno di un file.

  • Cambia tema: Usa l'opzione del menu Visualizza per impostare il tema chiaro o quello scuro.

  • Cambia carattere: Usa il comando del menu Modifica per impostare il carattere che desideri.

  • Mostra/Nascondi barra di stato: Usa l'opzione del menu Visualizza per mostrare o nascondere la barra di stato.

  • Abilita/Disabilita a capo automatico: Usa l'opzione del menu Visualizza per abilitare o disabilitare il ritorno a capo automatico.

  • Visualizza informazioni sull'app: Usa il menu denominato con un punto interrogativo per visualizzare le informazioni sull'editor.
